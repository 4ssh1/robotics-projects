# Robotics Learning Journey

Welcome to my robotics learning repository! I'm Sarah Nzeshi, a mechanical engineering graduate who ventured into software engineering during my third year of university. 
After spending the last few years building full-stack applications and diving deep into system design, I am now coming full circle to specialize in robotics. 

This repository serves as the central codebase for my ongoing transition, acting as a companion to the progress and lessons I share online as I work to bridge the gap between 
digital code and physical systems.

As I navigate through hardware constraints, sensor integrations, and physical prototyping, 
I am grounding myself in C++ fundamentals to ensure my firmware is as robust as the software systems I am used to building. You will find various mini-projects, scripts, and 
hardware tests gathered here, documenting the very real, unpolished steps of my learning process as I combine my mechanical engineering roots with modern software development.

If you want to run, test, or tinker with any of the sketches in this repository, the most straightforward approach is to use the standard Arduino IDE. You can download the 
latest version from the official Arduino website, clone this repository to your local machine, and open the respective .ino files directly in the editor. 
Just make sure you select the correct board and port in the IDE's tools menu before hitting compile and upload to flash the code to your microcontroller.

Feel free to look around, point out any code optimizations, or follow along with my journey. I will be updating this space regularly as I complete new learning modules, test 
new components, and tackle increasingly complex physical challenges.
